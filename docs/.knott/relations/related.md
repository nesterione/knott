---
name: related
symmetric: true
description: The two entities are worth reading together. The link goes both ways.
---
Use `related` between peers, such as two concepts that explain each other. Store the link on one side only: `knott refs` shows it from both sides (`←` stored by the other entity, `→` by this one, `⇄` by both). Storing it on both sides is valid but adds nothing.

When one entity is the subject of the other, use `about`. When one replaces or changes the other, use `supersedes` or `amends`.
