---
name: about
inverse: discussed_in
description: The source discusses the target, shapes its behaviour or enforces its rules. Read from the target, the source is where the target is discussed.
---
Use `about` when the target is the subject the source is written about: the concept a decision affects, the concept whose rule an issue code enforces. `knott refs` on the target lists these sources under `discussed_in`.

Prefer `related` between two concepts that are simply worth reading together; `about` points from a record to its subject, never between peers. When the source replaces or changes another record of the same kind, use `supersedes` or `amends` instead.
